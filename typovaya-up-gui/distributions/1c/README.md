# Локальная папка дистрибутива платформы 1С (Windows)

Сюда **вы кладёте сами** полный лицензированный дистрибутив платформы 1С с официного носителя/кабинета — **ничего не скачивается** из репозитория и оболочки.

## Что положить

В эту папку (или в подкаталоги на один уровень вглубь):

- основной установочный пакет `*.msi` (часто имя вида `1CEnterprise 8 (x86-64).msi` — **название зависит от поставки**, мы его не фиксируем);
- при наличии — языковой transform `*.mst` (например `1049.mst` для русского; если файлов несколько, в GUI можно выбрать папку и будет показан найденный список).

Содержимое этой папки **в `.gitignore`** — в git остаётся только этот README.

## Зачем

Для **сравнения выгрузок УП/БП** платформа 1С **не нужна** — достаточно OneScript.

Установка из этой папки нужна только если вы хотите локально получить **`ibcmd`** (компонент **CSServer** без службы кластера) для импорта черновика расширения. Запуск установки — **только по отдельной кнопке** в GUI, с подтверждением и UAC.

## Безопасность

- Не запускайте установку, если не уверены в источнике дистрибутива.
- Скрипт/оболочка **не меняют** уже установленную платформу молча и **не понижают** версию.
- Коды MSI **1603** / **1730** считаются ошибкой; после установки проверяйте наличие `ibcmd.exe` (кнопка «Проверить ibcmd» в GUI).
