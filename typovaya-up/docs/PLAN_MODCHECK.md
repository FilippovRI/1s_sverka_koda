Собрать **основную конфигурацию** (`restored`: тексты БП + заглушки) и **расширение** `УП_Доработки` без цикла «ibcmd → правка выгрузки руками → новая ошибка». Сначала — статическая замкнутость ссылок, затем правки только в генераторе.

## Правила проекта (инварианты генерации)

- **Form.xml в restored** — форма БП дословно; формы не режем. Неразрешённое закрывается заготовками и метаданными из БП.
- **Объект в УП** — состав как в УП + недостающие реквизиты и ТЧ из БП. **Объекта нет в УП** — из БП: заготовка или полные метаданные (Task, адресация).
- **DefinedType** — как в УП. При одном uuid и разных именах — имя БП; ссылки в расширении переименовать.
- **Ручные правки** в `restored`/`extension` запрещены; результат даёт только генератор.
- **Код УП** только в расширении: хуки `&ИзменениеИКонтроль`; `&Вместо` только обёрткой с `ПродолжитьВызов`.
- **Заимствованные формы расширения**: Form.xml как в БП, без стандартных команд; реквизиты/элементы/команды УП — программно в `ПриСозданииНаСервере` через `ЭтаФорма`.

## Метрика захода

- Число **неразрешённых ссылок по классам** (`modcheck_closure.json` → `counts`).
- Если **два захода подряд** метрика не падает — остановиться и доложить (не крутить ibcmd).

## Этап 1: что проверяет `ПроверкаЗамкнутости.os`

Вход: каталог `restored` (обязательно), опционально `--бп` / `--уп` для подсказок `inBp` / `inUp`.

За один обход все `*.xml` (включая Form.xml, Template.xml, метаданные):

- **cfg:** `*Ref.*`, `*Object.*`, `DefinedType`, `Characteristic`, регистры, `TypeSet`, маршрутизация BusinessProcess/Task (AddressingAttribute, AddressingDimension);
- **Form.xml**: `DataPath`, `CommandName`, `Picture`/`RowsPicture`, `StyleItem`/`style:`, типы реквизитов, колонки `v8:ValueTable` с cfg-типами;
- **Configuration.xml**: `ChildObjects` ↔ файлы/папки; дубликаты uuid/имени DefinedType;
- **Прочее**: CommonModule, Role, Subsystem, Enum/EnumValue, Constant, SessionParameter, FunctionalOption, CommonPicture, Language; `xr:Ref`, пути вида `Catalog.X.Attribute.Y`.

Выход (рядом с каталогом или `--json` / `--txt`):

- `modcheck_closure.json` — полный список неразрешённых, счётчики, время;
- `modcheck_closure.txt` — сводка и топ примеров.

Код выхода: **0** — всё разрешено, **1** — есть неразрешённые.

Запуск:

```text
oscript typovaya-up\src\ПроверкаЗамкнутости.os D:\typovaya-up-out-20261118u\restored --бп "D:\выгрузка БП" --уп "D:\Выгрузка УП"
```

(альтернатива: `oscript typovaya-up\src\ЗапускПроверкаЗамкнутости.os` с теми же аргументами)
