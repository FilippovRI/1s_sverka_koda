# Формы для ручного переноса (keep-up)

По итогам CheckModules **p2m3** vs эталон **p2g3c** (26.11.2026, Europe/Moscow).

- **19 форм keep-up** (этот документ): в **restored** — полный модуль формы и `Form.xml` из выгрузки УП, в расширение по ним ничего не пишется (уже лежащие файлы формы снимаются). В том числе `ОбщаяФорма.РегламентированнаяОтчетность`. Собственные и префиксные методы этих форм в расширение не переносятся.
- **9 чистых форм** (`typovaya-up/scripts/iik_manual_vmesto_forms.txt`): в restored — typovaya, тела БП и хелперы БП; в расширении — только `&Вместо`. После p2m3 у них не было `fair_added` ни в main, ни в ext.

Списки: `typovaya-up/scripts/iik_manual_keepup_forms.txt`, `iik_manual_vmesto_forms.txt`. Общий перечень 28 форм для пропуска pack1/pass2: `iik_manual_forms.txt`.

Не входят в списки: `Документ.БольничныйЛист.Форма.ФормаСписка`, `Документ.ЗаявленияОПредоставленииСведенийОТрудовойДеятельности.Форма.ФормаДокумента`, `Обработка.ДокументооборотСКонтролирующимиОрганами.Форма.УправлениеОбменом`. Не форма: `Справочник.БанковскиеСчета.МодульОбъекта`.
