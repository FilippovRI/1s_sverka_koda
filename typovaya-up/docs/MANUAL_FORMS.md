## Как переносить вручную

- `&Вместо("Имя")` — состав параметров как в БП; в расширении процедура `УП_Имя` с полным телом УП, без
  `ПродолжитьВызов`; в restored — тело БП.
- `&ИзменениеИКонтроль` — общий метод, отличия только вставки `// УП_начало`…`// УП_конец`.
- Свой метод — есть только в УП (нет в typovaya и в БП): полное тело и директива в модуле формы расширения;
  привязки команд/событий — в `Form.xml` расширения (заготовка, не полный `Form.xml` УП — из‑за типов загрузка
  может не пройти).
- Другая сигнатура — не `&Вместо`, а свой `УП_Имя`; привязки перенацелить. Разница только в «Экспорт» — не
  повод для отдельного метода.
- Методы typovaya, которых нет в БП, оставлять в основной форме (не удалять и не переносить — иначе ломается
  импорт `Form.xml`).
- Собственные методы расширения не видят процедур typovaya (разные модули компиляции). Такие вызовы делать из
  `&Вместо` или не звать typovaya по имени.
- Документы и регистры в расширение не переносим. Недостающие общие модули НСК/УП подключать в расширение.

### 19. `Справочник.СпособыОпределенияЦенКонтролируемыхСделок.Форма.ФормаЭлемента.Форма`

- УП: методов `УП_*` — 0; только в УП (нет typovaya и БП) — 0; вставок `// УП_начало` — 0. typovaya совпадает
  с УП, Form.xml typovaya совпадает с УП, модуль БП есть.
- Ошибка автопереноса: p2m3 main: процедура не определена (2). Исходная причина exclude/остатка p2g3c: В main
  эталона p2g3c остались ошибки «Переменная не определена» (ссылки на общие модули УП/НСК, которых нет в
  typovaya restored). Автоперенос тел в расширение эту основную конфигурацию не очистил; форма оставляется с
  полным УП-кодом для ручного переноса.
- Методы: `&Вместо` (1), сигнатура как в БП, в расширении процедура `УП_<Имя>` с полным телом УП, без
  `ПродолжитьВызов`; в restored — тело БП: ПриСозданииНаСервере.
- Форма расширения: Form.xml УП совпадает с typovaya — относительно typovaya реквизиты и команды в форму
  расширения добавлять не нужно.
- Модули: Нужны в расширении (документы и регистры не переносим): КонтролируемыеСделкиПовтИсп (нет в typovaya,
