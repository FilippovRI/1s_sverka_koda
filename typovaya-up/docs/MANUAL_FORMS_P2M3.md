## Почему в ext собственные методы не видят методы typovaya

Модуль формы расширения и модуль формы typovaya (restored) — разные модули компиляции. `&Вместо("Имя")` привязан к методу основной формы и проверяется в её контексте: вызовы typovaya-методов из тела хука CheckModules по расширению обычно принимает (в p2v при одних только `&Вместо` ext fair_added был 0). Собственные методы расширения (перенесённые УП-only и префиксные `УП_*`) компилируются только в модуле расширения: простое обращение к процедуре typovaya по имени для них «процедура не определена».

По факту p2m3: из 25 новых «процедура не определена» в ext 24 имени есть и в typovaya, и в restored, но нет в модуле расширения (вызываются из собственных/префиксных методов). Одно имя — `Записать` на ФормаОрганизации: это метод платформы/формы, его нет в модуле typovaya. Все 45 новых ошибок ext — только на формах, где есть moved или prefixed; у форм только с `&Вместо` (без своих методов) ext fair_added = 0.

Хелперы БП в итерации 2 убрали часть прежних NSK (fair_gone=41, все «переменная не определена»; официальных в main стало 146→141), но 23 «процедура не определена» в main остались — часть хелперов не добавилась (отсев по метаданным/реквизитам формы). Третью итерацию не делали.
