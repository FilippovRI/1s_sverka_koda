# Загрузка черновика через ibcmd (opt-in)

Флаги `Главный.os`: `--ibcmd-загрузка`, `--ibcmd-база`, опционально `--ibcmd-план` (только план в `ibcmd_load_plan.json`).

Перед import выполняется **`ibcmd infobase config extension list`** (8.5, §4.10.4.7.12):

- имя уже есть → `config import --extension=…` + `check` + `apply` (без `extension create`);
- пустая база → `extension create` → import → check → apply;
- есть только похожие имена (`УП_Доработки1` …) → **остановка**, без удаления.

Выгрузки УП/БП и файловая ИБ при сравнении не меняются; import трогает только ИБ при явном `--ibcmd-загрузка` без `--ibcmd-план`.

**Занятость базы (перед list/import):** для `--ibcmd-база` проверяются файлы `*.cfl` (в т.ч. `1Cv8.1CD.cfl`, `1Cv8.cfl`). Если база занята (Конфигуратор/сеансы) — остановка с сообщением, без import/apply и **без** принудительного завершения чужих сеансов. Для серверной ИБ — по тексту ошибки ibcmd (блокировка/lock/`1Cv8.1CD`).
