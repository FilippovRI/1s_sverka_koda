# Прототип: формы БП в restored + заимствованные формы в extension

Дата: 2026-11-24. Opt-in шаг, **по умолчанию выключен**. Текущий рабочий режим генератора (`--формы-из-уп`) не меняется: в `Главный.os` флаг пока не подключён (параллельная работа в той же ветке). Запуск — `scripts/run_forms_bp_proto.os`.

## Зачем

Сейчас формы restored целиком из УП, поэтому 330 ссылок на убранные общие модули только УП остаются в основной конфигурации. Подход прототипа:

- в `restored` — `Form.xml` и `Module.bsl` из БП (типовые);
- в `extension` — заимствованная форма: тело `Form.xml` = БП; реквизиты, элементы и команды только УП создаются программно в модуле (`ФормыПрограммныйСлойУп`, `&После("ПриСозданииНаСервере")`); отличия методов — `&Перед` / `&После` / `&Вместо` / `&ИзменениеИКонтроль`.

Формы только УП у объектов, общих с БП, этим срезом **не переносятся** (нет пары в БП): они остаются в todo / как собственные формы.

## Запуск

```
oscript typovaya-up/scripts/run_forms_bp_proto.os ^
  -и "D:\Выгрузка УП" -п "D:\выгрузка БП" -в "D:\typovaya-up-forms-proto" ^

  --forms "Catalogs\Организации\Forms\ФормаВыбора\Ext\Form.xml,Catalogs\Организации\Forms\ФормаОрганизации\Ext\Form.xml"
```

Классификация пишет `forms_bp_proto_summary.json` и `forms_bp_proto_items.csv`. Срез пишет `restored/`, `extension/`, `proto_stat.json`, при необходимости `proto_todo.txt`.

Исходные выгрузки и чужие каталоги сборки не изменяются.

## Срез «только модуль» (`module_only`)

Формы, где Form.xml УП и БП совпадают, а отличается только Module.bsl. В restored — модуль (и тело) из БП; в extension — заимствованная форма с хуками, без программного слоя XML.


Наложение среза на полные выгрузки: `scripts/overlay_forms_bp_proto.os`. Загрузка во временную базу `D:\typovaya-up-tmp-forms`: `scripts/load_forms_module_only.ps1` (копирует restored/extension из `typovaya-up-out-mf2` только чтением в `proto\load\`, затем overlay). ## Исправление CheckModules: типовые хелперы формы

CheckModules расширения не видит процедуры типовой (основной) формы, если их вызывают строки `&ИзменениеИКонтроль` или `#Вставка`. Для трёх общих форм (`ВводВременногоПароля`, `ОтключениеПодтвержденияКриптоопераций`, `СвязанныеДокументы`) генератор теперь дописывает в модуль расширения сами типовые хелперы как `&ИзменениеИКонтроль("Имя")` с телом из БП. Вызовы в типовых строках **не** переименовываются в `УП_*`.

Анализ берётся из уже отрисованного текста хуков (кроме `#Удаление`): поле `hookBody` в сравнении может быть пустым до отрисовки. API — `ДозаполнениеМодуля.ОчередьХелперовПоТекстуХуков` / `ОчередьХелперовТиповыхСтрокФормы` и `СтрокиКромеУдаления`. Поведение замыкания хелперов для **общих модулей** не менялось (по-прежнему только `#Вставка`).

Тест: фикстура `СпрХелпер` / `ФормаХелпер` в `tests/test_forms_bp_proto.os`.

`InternalInfo` / `xr:GeneratedType` у заимствованных объектов по-прежнему копируется из УП (и из целевого restored при overlay); это закреплено тем же тестом.

## Тело Form.xml в extension

Для всех срезов прототипа тело `Ext\Form.xml` в расширение **не пишется**. Форма наследуется из restored (там `Form.xml` БП). Полное тело на объекте-заглушке без реквизитов объекта даёт в Designer «Неверный путь к данным». Метаданные заимствованной формы и модуль (хуки и/или программный слой) остаются.

### 239 форм только со свойствами: не заимствовать автоматически

**Решение:** в restored оставлять форму БП; заимствованную форму с полным `Form.xml` **не** плодить; отличие писать в todo (`docs/FORMS_XML_PROPS_TODO.md` и `docs/forms-proto/props_*.txt`).

Обоснование:

1. typovaya — это UI БП; чисто визуальные отличия УП (заголовки, ширина, расположение поиска, картинки вроде `ДлительнаяОперация48` vs `…48БП`, UUID colorstyle) не должны подменять типовую форму в основной конфигурации.
2. Полное тело `Form.xml` в расширении на заимствованном объекте-заглушке уже ломало загрузку («Неверный путь к данным»).
3. 239 автозаимствований — большая хрупкая поверхность при том, что меняются только свойства уже существующих имён; программный слой умеет добавлять **имена**, а не надёжно переносить значения свойств.
4. Функциональные свойства (`CommandName`, `DataPath`, `MainTable`, `Field`, `QueryText` и т.п.) нельзя терять молча — их выше приоритетом в todo, разбор вручную, не авто-копия полного тела.

## Пропуски и устойчивость генератора

- Повторная генерация в тот же каталог перезаписывает блок хуков от маркера до конца модуля (иначе остаются старые короткие модули без типовых хелперов).
- Если модуль БП ссылается на общие модули, которых нет в typovaya (сравнение с выгрузкой УП), форма в срез не включается: в restored остаётся модуль typovaya, причина пишется в todo. Сравнение только с УП (не с уже собранной typovaya в mf2) даёт лишние пропуски: в срезе 109 из 23 таких пропусков фактически новые ошибки CheckModules основной дали 6 форм — их модули при загрузке оставлены typovaya (копия из mf2).
- Если `Form.xml` БП содержит `DataPath` на реквизиты, которых нет в метаданных typovaya/УП, форма пропускается (иначе ibcmd: «Неверный путь к данным»). Тест: `ФормаДп` / `РеквизитТолькоБп`.
- Если Form.xml БП ссылается на CommonPicture, которой нет в typovaya/УП, форма пропускается (иначе ibcmd: исключение XDTO на свойстве ValuesPicture). Тест: ФормаКк / КартинкаТолькоБп. На срезе both_differ таких форм 4: ЗаявлениеВФССОВозмещенииВыплатРодителямДетейИнвалидов/ФормаДокумента (СвернутьРазвернутьБЗК), УведомлениеОПрекращенииОтпускаПоУходуЗаРебенком/ФормаДокумента (Информация16АнимированнаяБЗК), ВходящийЗапросФССДляРасчетаПособия/ФормаДокумента (ИнформацияНовости16Анимированная), ОбщиеФормыСЭДОФСС/ТекущиеДелаПоСЭДО (Успешно32БП).
- Генератор пока не очищает выходные `restored/` и `extension/` в начале прогона: перед повторной генерацией их нужно удалить вручную, иначе пропущенные формы оставят старые файлы, и overlay утащит их в загрузку.
- `scripts/load_forms_module_only.ps1`: robocopy `/MIR` (не `/E`), чтобы в `load/extension` не оставались старые `Form.xml`; после CheckModules расширения выполняется CheckModules основной. Код выхода 101 у CheckModules ожидаем и пишется в лог.
