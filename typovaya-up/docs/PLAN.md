## Будущие regression (зафиксировать в тестах по мере этапов)

- `&Вместо` не должен **дополнительно** вызывать типовой расчёт без доказанной необходимости.
- Реквизиты форм: создание **до** первого использования; корректные типы/зависимости; нет дублей статика+runtime.
- Сложные формы → `manual` с конкретной причиной; исходные XML выгрузок не меняются утилитой по умолчанию.
