# Справочник экспортных API (typovaya-up)

Комментарии в коде — источник истины; здесь — контракты после этапа 2. Ошибки: без обёрток Попытка файловые/XML операции пробрасывают исключения платформы.

## НастройкиСравнения.os

| Функция | Вход | Выход / ошибки |
|---------|------|----------------|
| `ПрочитатьНастройки(Путь, Лог)` | XML merge settings | Структура с `Пути` (Соответствие); `НеСопоставлено` — нераспознанные Property. Нет файла → исключение при `ОткрытьФайл`. |
| `ПутьМодуля(ИмяОбъекта, Свойство)` | fullName + имя модуля | Относительный путь или `Неопределено`. |
| `ТипПоКаталогу(Каталог)` | Имя папки выгрузки | Имя типа метаданных или исходная строка. |

## Сравнение.os

| Функция | Вход | Выход / побочные эффекты |
|---------|------|--------------------------|
| `СравнитьВыгрузки(Исходная, Поставщик, Периметр, Лог)` | Две выгрузки, опц. периметр | Массив модулей; в `Лог` — строки о периметре. Алгоритм корзин/хуков **не** меняется здесь. |
| `СравнитьМодуль(Путь, ПутьИсх, ПутьПост)` | Пути к `.bsl` или `Неопределено` | Описание одного модуля. |

## ОтчетHTML.os

| Функция | Вход | Выход |
|---------|------|-------|
| `СобратьСводку(Модули, Мета)` | Результат сравнения | Структура для `summary.json` (counts, hooks, paths). Без записи на диск. |
| `ЗаписатьОтчет(...)` | Модули, сводка, каталоги | Пишет `summary.json`, `razbor_moduley.html`. |
