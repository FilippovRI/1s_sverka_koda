# Справочник экспортных API (typovaya-up)

Комментарии в коде — источник истины; здесь — контракты ключевых функций. Ошибки: без обёрток Попытка файловые/XML операции пробрасывают исключения платформы.

## Главный.os

| Функция / флаг | Назначение |
|----------------|------------|
| `РазобратьАргументы(Аргументы)` | Структура CLI: пути, `noReport`/`reportOnly`, `noSyntax`/`syntaxLimit`, формы, ibcmd; поле `errors`. |
| `--без-отчета` / `--no-report` | Не писать `razbor_moduley.html`; в `summary.json` остаются пути для `--только-отчет`. |
| `--только-отчет` / `--report-only` | Только HTML по готовому `--выход` (пути из `summary.json.meta`); без extension/restored/самопроверки; лог — `report_only_log.txt`. |
| `--без-синтаксиса` / `--no-syntax` | Отключить bsparser в самопроверке (`syntax_errors`). |
| `--синтаксис-лимит N` | Проверить не больше N модулей (0 — все). |
| Прогресс / `timings` | `[шаг N]` в консоль и `log.txt`; секунды в `summary.json` → `timings` (`readDumps`, `readSettings`, `compare`, `reportHtml`, `extension`, `helpers`, `restored`, `selfCheck`, `syntax`, `total`, …). |

## НастройкиСравнения.os

| Функция | Вход | Выход / ошибки |
|---------|------|----------------|
| `ПрочитатьНастройки(Путь, Лог)` | XML merge settings | Структура с `Пути` (Соответствие); `НеСопоставлено` — нераспознанные Property. Нет файла → исключение при `ОткрытьФайл`. |
| `ПутьМодуля(ИмяОбъекта, Свойство)` | fullName + имя модуля | Относительный путь или `Неопределено`. |
| `ТипПоКаталогу(Каталог)` | Имя папки выгрузки | Имя типа метаданных или исходная строка. |

## Сравнение.os

| Функция | Вход | Выход / побочные эффекты |
|---------|------|--------------------------|
| `СравнитьВыгрузки(Исходная, Поставщик, Периметр, Лог)` | Две выгрузки, опц. периметр | Массив модулей; в `Лог` — строки о периметре. |
| `СравнитьМодуль(Путь, ПутьИсх, ПутьПост)` | Пути к `.bsl` или `Неопределено` | Описание одного модуля. |

## СинтезХуков.os

| Функция | Назначение |
|---------|------------|
| `ПредложитьХук(ТиповоеТело, ДоработанноеТело)` | `decision`/`hook`/`hookBody`; для `&ИзменениеИКонтроль` — дословное типовое тело, маркеры УП внутри блоков, `// АПК:` не УП. |
| `ПроверитьЦелостностьТелаИк(Тело)` | Маркеры `#Вставка`/`#Удаление` не режут многострочный оператор. |
| `ВосстановитьБазовыйТекстТиповогоИзХука` | Тело без вставок → должно совпасть с типовым. |

## ДозаполнениеМодуля.os

| Функция | Назначение |
|---------|------------|
| `СтрокиВставок(Текст)` / `ПереписатьВызовыВоВставках` | Анализ и rename `УП_` **только** внутри `#Вставка`. |

## СамопроверкаВыхода.os

| Функция | Назначение |
|---------|------------|
| `ПроверитьКаталогВыхода(..., КореньИсходной, ПараметрыСинтаксиса)` | `self_check.json`: локальные вызовы, ИК, `e1000001-*`, `invalid_class_id`, `duplicate_method_definitions`, `syntax_errors`, вызовы в restored, корзины. |
| `ПлатформенныеClassIdКонфигурации` / `ПроверитьClassId` | ClassId — константы платформы; эталон — ClassId выгрузки УП или платформенный набор. |
| `ПроверитьПовторыМетодов` | Повторные объявления в `extension`/`restored`. |
| `ПроверитьСинтаксис` / `МсСинтаксиса` | bsparser; отключается `--без-синтаксиса`. |

|---------|------------|

## ЧерновикРасширения.os

| Функция | Назначение |
|---------|------------|
| `Записать(...)` | `extension/` + `restored/`; счётчики; InternalInfo из `extension_meta` (ObjectId детерминированны, ClassId из шаблона). |
| `ИдётВРасширение(Мт)` | Авто-хук или `newMethod`. |
| `ОтрисоватьМетод` / `ВосстановитьТекст` | Текст хука / restored; dedup объявлений в модуле. |
| `СкелетInternalInfoКонфигурации` / `АктуализироватьUuidInternalInfo` | Шаблон InternalInfo + замена `e1000001-*`. |

## БезопасностьПереноса.os

| Функция | Назначение |
|---------|------------|
| `НуженПродолжитьВызовВЧерновике` | Всегда `Ложь` — хвост в черновик не дописывается |
| (СинтезХуков) `ОценитьВместоПродолжитьВызов` | Один отдельный вызов → тело целиком; иначе `manual` |
| `ДиагностикаВызовов` | Блокирует auto при динамических вызовах |
| `ДопустимоАвтоВместо` | Обёртка над диагностикой |

## РазборМетодов.os

| Функция | Назначение | Ограничения |
|---------|------------|-------------|
| `РазобратьМодуль(Текст)` | Методы + норм. код вне методов | Лексический срез; `#Если` в теле не интерпретируется |
| `УбратьКомментарий(Стр)` | Срез до `//` вне строки | `"""` как escape; не `#` и не `|` |
| `ЭтоМаркерКонцаМетода(Стр, МаркерНРег)` | Граница метода | Только голый `КонецПроцедуры`/`;` |
| `РазобратьОбъявление(Стр)` | Имя до `(` | Многострочная сигнатура — до 5 строк |

## ОтчетHTML.os

| Функция | Вход | Выход |
|---------|------|-------|
| `СобратьСводку(Модули, Мета)` | Результат сравнения | Структура для `summary.json` (counts, hooks, paths). Без записи на диск. `timings` добавляет `Главный`. |
| `ЗаписатьОтчет(...)` | Модули, сводка, каталоги | Пишет `summary.json` + HTML. |
| `ЗаписатьHtml(...)` | То же | Только `razbor_moduley.html` (для `--только-отчет`). |
| `ПрочитатьСводку(КаталогВыхода)` | Папка выхода | Разбор `summary.json` или `Неопределено`. |
