# Грабли OneScript (typovaya-up)

Общие грабли платформы — в upstream `skills-onescript/skills/onescript/pitfalls.md` (MIT). Ниже — то, что чаще мешает этому репозиторию.

## Язык и имена

- Не называй переменные и функции: `И`, `Или`, `Не`, `Новый`, `Символы`, `Строка`, `Число`, `Дата`, `Булево`, `Тип`, `Вычислить`.
- `Новый Структура("a,b", 1, 2)` — ключи перечисляются в **первой** строке через запятую.
- У `Для` нет шага; обратный обход — через `Пока`.

## Соответствие и циклы

- `Для Каждого КЗ Из Соответствие` даёт элемент с `.Ключ` и `.Значение`; для массива структур проще итерировать сам массив.

## Имена процедур vs встроенное API

- В OneScript 2.x имя процедуры может совпадать с глобальным API (пример из практики: процедура `ЗаписатьJson` ломает вызов). Для JSON-отчётов используй уникальные имена (`ЗаписатьОтчетФормJson` и т.п.).

## Загрузка сценариев

- Из теста: `ЗагрузитьСценарий(Путь)` возвращает объект с **Экспорт**-методами; внутренние функции того же файла снаружи не видны.
- Модули, подгружаемые только из `Главный.os`, всё равно нужны в рантайме — не удалять по статическому grep.

## JSON

- Предпочтительно ручная сериализация или встроенные `ЧтениеJSON`/`ЗаписьJSON` там, где уже принято в соседнем коде; не тянуть пакет `json` без нужды.
